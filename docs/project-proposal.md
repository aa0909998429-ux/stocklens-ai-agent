# StockLens 期末專案發想

## 專案名稱

**StockLens：結合 Tool Use 與 Planning 的 AI 股市歷史資料分析 Agent**

## 專案目標

一般使用者看到股價、成交量與技術指標時，常不知道數字代表什麼。如果只請語言模型回答，也可能產生沒有經過實際計算的內容。本專案將讓 Gemini 負責理解問題、規劃與選擇工具；報酬、移動平均、波動度與最大回撤則交由 Python 工具計算，最後再由 AI 根據工具結果產生繁體中文解讀。

本系統定位為歷史公開資料的學習與分析工具，不預測保證未來漲跌，也不提供買進、賣出或保證獲利的投資建議。

## 操作流程

1. 使用者輸入股票代號、日期區間與分析需求，或上傳歷史股價 CSV。
2. Planning Agent 判斷需要執行的分析步驟。
3. Tool Use Agent 選擇資料驗證、報酬率、均線、波動度、最大回撤及圖表工具。
4. Python 工具執行實際計算並回傳結構化結果。
5. Gemini 根據結果產生摘要，清楚區分事實、解讀與限制。
6. Gradio 顯示圖表、數值、資料日期、來源及工具呼叫紀錄。

## 使用技術

- Google Gemini API：理解問題、Planning、Function Calling 與結果解讀
- Python、Pandas、NumPy：資料清理與指標計算
- Plotly：互動式股價、均線及成交量圖表
- Gradio：輸入、圖表、摘要與工具紀錄介面
- CSV：最小可行版本的可靠資料輸入
- TWSE OpenAPI／Alpha Vantage：後續公開資料來源候選

## 最小可行版本

1. 上傳固定格式 CSV。
2. 檢查欄位、日期、缺失值與重複日期。
3. 計算期間報酬、5 日與 20 日均線、波動度及最大回撤。
4. 產生股價、均線及成交量圖表。
5. 顯示工具名稱、輸入參數與結果。

CSV 模式不依賴即時 API，即使外部 API 額度不足或無法連線，也能完整展示核心流程。

## 測試方式

- 使用正常 CSV 驗證計算與圖表。
- 移除必要欄位，確認系統拒絕分析並顯示原因。
- 加入缺失值與重複日期，確認資料驗證工具能發現。
- 使用人工可計算的小型資料驗證報酬率與最大回撤。
- 以相同資料重複詢問，確認數值不被 AI 改寫。
